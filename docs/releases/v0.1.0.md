# v0.1.0 Release Notes

发布日期：2026-08-23

v0.1.0 是 LY Fullstack 的第一个公开工程基线。它提供可以真实运行的管理后台与管理 API，重点解决全栈项目从目录组织、数据库、认证权限到测试和部署缺少统一底座的问题。

## 版本亮点

### 通用管理核心

- Vue 3 + Rsbuild + Element Plus 管理后台。
- NestJS + Fastify 管理 API。
- JWT 登录、刷新会话、退出登录和修改密码。
- 用户、角色、菜单和五表 RBAC。
- 数据库动态菜单与 Lucide 图标白名单。

### 数据库与初始化

- PostgreSQL 18 + Prisma 7 driver adapter。
- 可追踪的 migration 和幂等 Seed。
- `pnpm setup` 自动创建数据库、表结构和本地默认管理员。
- Linux + PostgreSQL GitHub Actions 验证同一套 Setup 流程。

### Admin 体验

- 独立设计的深浅主题与 Element Plus Sass 变量覆盖。
- 登录页、Dashboard、系统管理和展示页面。
- 响应式侧栏、动态面包屑、通知、主题切换和修改密码。
- 版本检测、更新提示与同源离线缓存。

### 工程能力

- pnpm workspace + Turborepo Monorepo。
- 应用注册表、交互式开发启动器和 NestJS 服务生成器。
- ESLint、Prettier、Husky、commitlint 和架构边界检查。
- Admin、Admin API、Shared 与 Charts 的 Rstest 测试。
- Playwright 覆盖登录、会话恢复、动态菜单和退出登录。

## 快速开始

```bash
pnpm install
pnpm setup
pnpm dev
```

本地首次初始化管理员为 `admin / admin123`。该凭证只用于本地开发；生产环境必须使用强密码完成首次 Seed，具体步骤见 [`../deployment.md`](../deployment.md)。

## 兼容要求

- Node.js >= 22.19.0。
- pnpm >= 11 且 < 12。
- PostgreSQL 18，或由项目 Compose 启动的 PostgreSQL 18。
- 现代 Chromium、Firefox 或 Safari 浏览器；当前 CI 冒烟测试固定运行 Chromium。

## 验证方式

```bash
pnpm check
pnpm test:e2e
```

`pnpm check` 覆盖架构、类型、Lint、格式、单元测试、服务模板和生产构建。`pnpm test:e2e` 需要已经执行 `pnpm setup`，并会启动 Admin API 与 Admin 完成真实浏览器流程。

## 架构边界

当前版本是模块化单体与多应用 Monorepo，不是微服务平台。它没有 API 网关、服务发现、分布式追踪和分布式事务。具体 C 端业务也不会在需求未知时以空应用形式进入核心仓库。

下一阶段将继续稳定当前版本，并规划独立的 NestJS 微服务解决方案。规划内容不属于 v0.1.0 已有能力。

## 已知限制

- 公开只读 Demo 因服务器尚未准备而延期。
- 官方部署方案已经形成文档，但自动化 CD 尚未实现。
- Playwright 当前聚焦 Chromium 关键流程，不代表完整跨浏览器兼容矩阵。
- Dashboard 示例数据用于展示 UI，不代表已经接入真实监控平台。
- 通知和展示页面属于交互示例，不应被描述为完整业务模块。
